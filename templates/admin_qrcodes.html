Un QR code par table pour les commandes sur place. Le client qui scanne le QR code d'une table commande sur place : la cuisine voit directement le numéro de sa table. Le QR code général (ou le lien de votre menu) sert aux commandes à emporter, passées à distance : le client indique son prénom, son téléphone et l'heure de retrait. Si les commandes à emporter ne sont pas activées, ce lien affiche votre menu en consultation seulement.

Ajouter un code QR pour une table

Créez un QR code par table et imprimez son autocollant : c'est ce code qui permet au client de commander sur place.

Commandes en attente par table

Pour éviter les fausses commandes, une table ne peut pas envoyer de nouvelle commande quand trop de ses commandes attendent déjà d'être prises en charge par la cuisine (sur les 15 dernières minutes). Dès qu'une commande passe en « En préparation », elle ne compte plus. Augmentez cette limite si de grandes tables commandent depuis plusieurs téléphones.
