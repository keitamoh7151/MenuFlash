Un QR code par table pour les commandes sur place. Le client qui scanne le QR code d'une table commande sur place : la cuisine voit directement le numéro de sa table. Le QR code général (ou le lien de votre menu) sert aux commandes à emporter, passées à distance : le client indique son prénom, son téléphone et l'heure de retrait. Si les commandes à emporter ne sont pas activées, ce lien affiche votre menu en consultation seulement.
